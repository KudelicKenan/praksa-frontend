F1 SpeedZone je interaktivna web stranica posvećena ljubiteljima Formule 1. Projekt je nastao kao završni rad sedmodnevnog učenja osnova web razvoja (HTML, CSS, JavaScript i Bootstrap).

## 🛠️ Tehnologije
- **HTML5** & **CSS3** (Custom animacije i gradijenti)
- **JavaScript (ES6)** (Manipulacija DOM-om, Array metode)
- **Bootstrap 5** (Layout i Modal komponente)
